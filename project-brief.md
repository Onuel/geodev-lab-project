# My Project brief

Which settlements in Eti-Osa Local Government Area that are located on low-lying land and within 200 meters of a water course?

## The Data I Need
-Settlement Extents (GRID3)- https://data.grid3.org/
GeoPackage/Vector- Size depends on download

-Digital Elevation Model (DEM)-OpenTopography: https://portal.opentopography.org/
Tile Dependent

-Watercourses, Lagoon & Coastline-(OpenStreetMap) using the QuickOSM plugin to download only waterways, coastline, and lagoon features for Eti-Osa.

-Eti-Osa LGA Boundary - GADM/GRID3-GeoPackage/Vector -2.6MB for GADM
